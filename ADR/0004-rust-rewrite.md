# Rust へ書き直す

- 状態: 却下
- 日付: 2026-07-07 提案、2026-09-08 クローズ

## 背景

- Go 実装を Rust へ全面的に書き直す提案が出た。コマンド・フラグ・出力・キャッシュ形式・終了コードの互換を保ち、実データで新旧の出力をバイト比較して一致を確かめていた
- 提案のベンチではコールドの reindex が1.36倍速くなる一方、起動（`version`）は5.3msから5.9msに遅くなった

## 決定

書き直しをマージせず、Go のまま続ける。クローズの理由は記録されていない。

## 結果

提案と同じ日に、Go のまま読み込みバッファを広げ、ファイルを並列に処理して、コールドの reindex を4.4倍速くした。
