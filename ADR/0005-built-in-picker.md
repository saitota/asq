# 対話選択を内製ピッカーにする

- 状態: 採用（[0003](0003-fzf-picker.md) を置き換え）
- 日付: 2026-07-07

## 背景

- 対話選択は外部の fzf を呼び出す方式で、別途インストールが必要だった
- プレビューは、選択行を動かすたびに子プロセスがキャッシュ JSON（約10MB）を読み直し、1回に約70msかかっていた

## 決定

- bubbletea v2 を使い、asq のプロセス内で動くピッカーを作って `/dev/tty` に描く
- 検索は部分一致にして空白区切りの語をすべて含むものを残し、fzf のあいまい一致と拡張構文はやめる
- `list --fzf` の行と、その行を位置引数で受け取る仕組みは外部ピッカー向けに残す

## 結果

- fzf が不要になり、プレビューの子プロセスが無くなった
- bubbletea v2 の要求で、Go 1.25 以上が必要になった
- セッション本文に ANSI が含まれると行が短く切れるため、描画前に除去し、幅計算を ANSI 対応にした。cli と tui に重複した処理は後に `ansitext` へ集めた
