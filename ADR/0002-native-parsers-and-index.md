# セッションを自前のパーサで読み、ローカルにインデックスする

- 状態: 置き換え済み（[0007](0007-delegate-sessions-to-agentsview.md)）
- 日付: 2026-05-26

## 背景

各エージェントはセッションを非公開の形式でファイルに保存している。

## 決定

- エージェントごとにファイルの発見処理とパーサを用意し、共通のセッションモデルに正規化する
- 結果は単一の JSON ファイルにキャッシュし、mtime・サイズ・パーサのバージョンが変わったファイルだけ読み直す。当初の計画で保存先の候補にしていた SQLite FTS5 は使わない
- セッション名は Codex の `session_index.jsonl`、Copilot の `workspace.yaml`、Cursor の `store.db` といった付随ファイルから読む

## 結果

- 各エージェントの形式変更と、Cursor の非公開の内部実装（SQLite、パスのエンコード規則）への追従が続いた
- 付随ファイルの知識を各エージェントのパッケージに集め、読めなくてもセッションは落とさず警告にした
- パーサのバージョンをエージェントごとに分け、パーサを変えたエージェントのキャッシュだけを無効にした
- 対話コマンドのたびに全体を読み直して保存していた。変化があった時だけ保存し、読み込みはバッファの拡大と並列化で速くした
