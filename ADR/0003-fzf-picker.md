# 対話選択を fzf に任せる

- 状態: 置き換え済み（[0005](0005-built-in-picker.md)）
- 日付: 2026-05-26

## 背景

当初の計画では外部の fzf と組み合わせやすい出力を先に作り、内蔵 UI はパースとインデックスが安定してから検討するとしていた。

## 決定

- 引数の無い `resume` は fzf を起動し、タブ区切り行から選ばせる
- ID や検索用の全文は ANSI conceal で隠したまま検索対象にし、プレビューは fzf から `asq preview` を呼ぶ

## 結果

- fzf のインストールが必要だった
- 行レイアウトに依存する契約が生成側・fzf の引数・受け取り側に散っていたため、`cli/selection.go` の定数に集めた。タブ区切り行そのものは、内製ピッカーへの移行後も `list --fzf` に残っている
